5Behind the scenes — honesty gates & what can skip

SfM fails / declines
Orchestrator tries COLMAP then Fake backend; if all fail → ReconstructionOrchestrationError with full attempt log. No invented geometry.
No measured baseline
World stays RELATIVE — unit-less model distances, honestly noted in world.metadata["scale"].
Depth / perception unavailable
Stage skipped with a recorded reason; structural world is preserved. Never silently degraded.
Export format missing
UnsupportedExportFormatError — IFC needs IfcOpenShell; never writes an empty file.
Dense MVS escalation
Only when measured sparse-model properties justify it; the dense cloud is judged against the sparse world and kept only if better.
Orphaned jobs
Recovered on API startup (reconstruction/proc.py); adoption conflicts quarantined before the worker starts.
